I have experience in fintechs and technology for financial services, having worked as mid-level and senior developer, Tech Lead and IT specialist. I work with backend, systems architecture and technical leadership.

I work across the whole lifecycle: requirements gathering, planning, design,
coding, testing, deployment, documentation and maintenance.

- **Backend and REST APIs** in Java, Node/TypeScript and Python
- **AWS architecture**: Lambda, API Gateway, S3, EC2, Batch, SQS, DynamoDB, RDS
- **Data modeling and administration** focused on integrity, performance and security
- **Systems analysis**: use cases, UML diagrams, database modeling
- **Infrastructure and automation**: Docker, Kubernetes, CloudFormation, Jenkins
- **Technical leadership**: code review, unblocking, estimates, crisis management, career development

My experience fits senior backend, Tech Lead and AWS software engineering roles. In my own projects I also work on AI agent integration and developer tools.
