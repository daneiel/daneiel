### Чем я занимаюсь

У меня есть опыт в финтехе и технологиях для финансовых услуг: я работал разработчиком уровня middle и senior, Tech Lead и IT-специалистом. Занимаюсь бэкендом, архитектурой систем и техническим лидерством.

Работаю на всём жизненном цикле: сбор требований, планирование, проектирование,
разработка, тестирование, развёртывание, документация и сопровождение.

- **Бэкенд и REST API** на Java, Node/TypeScript и Python
- **Архитектура AWS**: Lambda, API Gateway, S3, EC2, Batch, SQS, DynamoDB, RDS
- **Моделирование и администрирование данных** с упором на целостность, производительность и безопасность
- **Системный анализ**: варианты использования, UML-диаграммы, моделирование БД
- **Инфраструктура и автоматизация**: Docker, Kubernetes, CloudFormation, Jenkins
- **Техническое лидерство**: код-ревью, устранение блокеров, оценки, антикризисное управление, развитие карьеры

Мой опыт подходит для позиций senior backend-разработчика, Tech Lead и инженера ПО с AWS. В собственных проектах я также занимаюсь интеграцией ИИ-агентов и инструментами для разработчиков.
